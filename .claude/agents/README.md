# カスタムエージェント

このディレクトリには、UMALOGI プロジェクト用のカスタムエージェント定義を配置します。

| ファイル | 役割 |
|---|---|
| `data_engineer.md` | データエンジニアエージェント — DB スキーマ・マイグレーション・データパイプライン担当 |
| `ml_engineer.md`   | ML エンジニアエージェント — 特徴量設計・モデル訓練・バックテスト担当 |

## 新しいエージェントの追加

スクレイピング専用エージェント、通知エージェント、評価エージェントなど、
役割ごとに `<role>.md` ファイルを作成してください。

各ファイルには以下を記載すること:
- エージェントの役割と責任範囲
- 使用するツール・スクリプトの一覧
- 入出力インターフェース
- 参照する `.claude/skills/` ドキュメント
