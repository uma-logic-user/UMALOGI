## 1. 目標と収益モデル

| 項目 | 値 |
|------|----|
| 年間目標利益 | **600万円**（月50万円） |
| 主力収益 | サブスクリプション **月額5,000円 × 100人 = 月50万円** |
| 補助収益 | note単発記事（500〜1,000円）・的中報告によるフォロワー資産化 |
| 実弾投資収益 | **当面は計上しない**（W-078 OOSゲート通過まで実弾は単複ロック維持） |

収益の柱を「予想の販売」に置き、実弾投資は「製品の信頼性を証明するトラックレコード」と
位置づける。これにより自己資金リスクと収益が分離され、月次キャッシュフローが安定する。

## 2. 製品（何を売るか）— すべて実装済み・完全自動生成

週末の開催日朝、本番オートパイロット（`today_auto_runner._run_one_day`）が
`outputs/marketing/YYYYMMDD/` に以下を**人手ゼロ**で生成する:

| ファイル | 用途 | 配布 |
|---|---|---|
| `free_pick.md` | 勝率特化の無料予想（盾）— 信頼獲得 | X 無料公開 |
| `hit_report.md` | 前日実績（真コスト基準・負けも公開） | X 無料公開 |
| `sns_teaser.md` | **Leak Story＋EVチラ見せ**（最大EVだけ見せ買い目は隠す） | X 無料公開 |
| `premium_sanren.md` | **三連単・三連複 EV1.30超フォーメーション＋参考ベット額** | 購読者限定 |
| `video_script.md` | ショート動画台本（TikTok/YouTube Shorts 展開用） | 制作素材 |

実証スモーク（2026-06-07 実データ）: 22レース・245点の高EV候補を抽出し、
チラ見せには実績「26点中11点的中・回収率164%」が自動挿入された。

## 3. 差別化戦略 — 「Leak Story」＝誠実さを売る

競馬予想商材の市場は「盛った的中報告」で飽和しており、購入者の不信が最大の参入障壁。
UMA-Logic は逆張りで**誠実さそのものを商品化**する:

1. **自らリーク監査を行い、回収率1173%の幻を公開前に棄却した**事実を物語る。
2. 残ったのはカンニングなしOOSの **三連系 回収率110%（400レース）** という現実の数字。
3. 負けた日の収支も `hit_report.md` で必ず公開する（実装済み・自動）。
4. プレミアム側にも「推定オッズである」「1日の結果でなく長期の期待値で」と明記（実装済み・自動）。

この文脈は模倣困難（実際にリーク監査のコードと記録 `scripts/ablation_leak_audit.py` /
`docs/roi_breakthrough_strategy.md` が存在する）であり、長期LTVの源泉になる。

## 4. 集客ファネル

```
X 無料ポスト（free_pick / hit_report / sns_teaser）
   │  毎開催日 自動生成 → 手動投稿（将来: API自動投稿）
   ▼
プロフィール → note 無料記事（Leak Story 全文・検証方法の公開）
   │
   ▼
note 有料単発（プレミアム1日分のサンプル 500円）→ 体験
   │
   ▼
月額サブスク 5,000円（premium_sanren.md 毎開催日配信＋資金管理ガイド）
```

### 価格の根拠
- 三連系フォーメーションは1開催日あたり数十点。購読者が1点100円で張っても
  月の投資額は数万円規模であり、5,000円は「情報コスト10%前後」で妥当域。
- 競合の競馬予想サブスクは月3,000〜10,000円帯。中央値やや下で参入し、
  実績蓄積後に上位プラン（資金管理シミュレーション付き 9,800円）を追加。

## 6. リスクと対処

| リスク | 対処 |
|---|---|
| モデル成績の悪化（負け月） | 負けも公開する設計が前提のため解約率への影響を緩和。見送り規律（候補なしの日は「買わない」と明言）を既に実装 |
| 推定オッズと実オッズの乖離 | premium_sanren.md に乖離注意を常設掲載済み。W-080 オッズ時系列蓄積後に推定精度を再較正 |
| netkeiba/JVLink 障害 | 本セッションの堅牢化4パッチで自動運用のクラッシュ経路を遮断。二重フォールバック維持 |
| 予想販売の法的リスク | 個別の投資助言ではなく「AIの計算結果の提供」と明示。返金規定・免責をnote/サブスク規約に明記（開設時に対応） |
| 実弾解禁の誘惑 | W-078 OOSゲート＋破産確率1%未満制約（recommend_portfolio_stakes）を通過するまで bet_policy の単複ロックを変更しない |

## 7. 実弾投資の解禁条件（W-078 ゲート・参考）

`src/ml/bankroll_manager.py` のシミュレーションにより、解禁時の資金管理は既に定量化済み:

- 三連系5点ポートフォリオ（EV 2.0〜2.8）の実証値:
  - 1/10 Kelly: P(破産) 0.0%・300開催日で資金中央値 8.5倍
  - Kelly分数 0.20: P(破産) 0.83% < 1% ← `recommend_portfolio_stakes` の推奨上限
  - フル Kelly: P(破産) 40.5% → 禁止
- 解禁の前提: 全期間OOS標本でのROI再確認＋「現行固定Kelly vs 動的管理」の比較検証。
