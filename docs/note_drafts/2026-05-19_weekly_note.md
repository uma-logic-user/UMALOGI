## 🧠 AIコラム: W-004「大衆心理乖離スコア」とは

今回のコラムでは、UMALOGIが密かに最重要視している特徴量の一つ、
**W-004「大衆心理乖離スコア（Crowd Bias Score）」** を解説します。

### なぜオッズは「真の確率」を反映しないのか

競馬のオッズは **多数の馬券購買者の集合知** によって形成されます。
しかし、この「集合知」には構造的な偏りが存在します。

| バイアスの種類 | 具体例 |
|---|---|
| **有名馬人気バイアス** | メディア露出が多い馬に過剰な人気が集中 |
| **前走成績バイアス** | 「前走1着」の馬を盲目的に買う傾向 |
| **騎手人気バイアス** | トップ騎手乗り替わりで実力以上の人気に |
| **逃げ馬過小評価** | 先行馬・差し馬への偏重で逃げ馬が過低評価 |

### W-004の仕組み

UMALOGIのW-004スコアは、以下の計算で「市場の歪み」を定量化します:

```
W-004 = (モデル確率 - オッズ換算確率) × 調整係数

オッズ換算確率 = 1 / (単勝オッズ × JRA控除率補正)
調整係数       = 人気順位 × 頭数係数
```

**W-004 > 0**: モデルがオッズより高く評価 → **穴馬候補**（市場が過小評価）

**W-004 < 0**: モデルがオッズより低く評価 → **消し候補**（市場が過大評価）

### なぜこれが重要か

複勝の期待値（EV）は単純に以下で計算できます:

```
EV = P(複勝圏) × 複勝払戻倍率
```

W-004スコアが高い（市場が過小評価している）馬は、
**払戻倍率が高め** かつ **モデル確率が高め** という
期待値最大化に最適な状態にあります。

> 💡 **実例**: 単勝20倍の8番人気馬で、モデルが「複勝圏確率30%」と算出し、
> 複勝払戻が3.0倍と予想される場合のEV = 0.30 × 3.0 = **0.90**。
> さらにW-004スコアが+0.15加算されれば EV = **1.05** → 買い目に昇格。
