## 中期フェーズ: 地方競馬（NAR）共通コア化による24時間365日自動投資（2026-Q4〜2027-Q1）

### コンセプト

JRA（土日開催・週2日）の予想AIを **地方競馬（NAR: 毎日開催）** へ拡張し、
週7日・年365日の自動投資体制を確立する。

予測・期待値計算の共通コア（`src/ml/`）はそのまま維持し、
データ取得層のみを「プロバイダー」として差し替えることで実現する。
詳細アーキテクチャは `docs/5_nar_integration_spec.md` を参照。

## 長期フェーズ: Next.js + FastAPI + PostgreSQL によるWebアプリ化（SaaS）と一般開放（2027-Q2以降）

### コンセプト

現在の「個人用ダッシュボード（ローカルNext.js）」を、
**外部ユーザーが利用できるSaaS型Webサービス**に転換する。

- バックエンド: **FastAPI**（Python。現在の予測エンジンをそのままAPI化）
- データベース: **PostgreSQL**（SQLiteから移行、マルチテナント対応）
- フロントエンド: **Next.js**（現行のUIを認証・課金対応に拡張）
- インフラ: Railway / Render / AWS ECS（コンテナ化）
