- 三連単の的中率 0.8% は理論値（≈1/3 ≈ 1,320点 / 18!）を大きく下回る
- 1軸フォーメーション（馬連）は最大ROI 57.8%。多点展開のコストが回収を圧迫
- **軸馬の勝率精度向上**が最優先課題。本命スコア上位2頭が1・2着に来る確率を高めること
