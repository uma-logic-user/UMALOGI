## 1. 3連系「本気」アンサンブル（gachi_trifecta / W-095）

買い目を当てにいく 3 連系エンジン。単一スコアではなく**役割の異なる 2 系統を
アンサンブル**して軸と紐を選び分ける。

| 役割 | 選定ロジック | 重み/設定 |
|------|------------|-----------|
| 軸（担保） | 本命勝率ランク + 複勝率ランクの**合算が小さい**上位馬 | 上位 `_N_AXIS=2` 頭 |
| 紐（妙味穴） | 軸を除き**卍 EV 降順**（人気の盲点） | 上位 `_N_PARTNERS=4` 頭 |
| 確率推定 | Harville 公式（本命勝率ベクトルを正規化） | 馬連/馬単/三連複/三連単 |
| EV 付与 | `OddsEstimator.ev`（軸単勝オッズ×券種スケール） | 券種別 EV キャップ |

点数キャップ（過剰購入の抑制）:

- 馬連 `_MAX_UMAREN=6` / 馬単 `_MAX_UMATAN=6` / 三連複 `_MAX_TRIO=8` / 三連単 `_MAX_TRIFECTA=12`

> 注: アンサンブルの「重み」は固定の係数ではなく**ランク合算（軸）と EV 降順（紐）という
> 選定規則**で表現される。軸＝的中率の担保、紐＝回収率の妙味、の役割分担。
> 実弾単複ロックの外（記録専用 model_type `本気3連系`）。

> ＝当初の +5.4pp は **完全なサンプリングノイズ**。複数 cutoff の平均は明確に**マイナス**。

### 結論・本番反映の可否（最終・6 cutoff ウォークフォワード確定）

- **`prev_trouble_proxy` 単体の改善は再現しない**: 6 cutoff の平均 ΔROI = **-8.15pp**、
  改善したのは 2/6（33%）のみ、ΔAUC も一貫してわずかに悪化（平均 -0.0027）。
  当初 +5.4pp に見えた cutoff は標本変更で -15.6pp に反転＝**サンプリングノイズ確定**。
- **全新特徴量セットも一貫悪化**（-1.7pp / -22.5pp）。
- **「BASE + prev_trouble_proxy」を正式 V2 にはしない**: そもそも `BASE` は寄与分離用の
  6 列研究ベースラインであり、本番 V2（`HonmeiModelV2`）が使う **69 列 `FEATURE_COLS`**
  （U-score 18因子・騎手/調教師・調教・直近着順 等）とは別物。7 列モデルへの差し替えは
  本番特徴量 63 列を捨てる重大なダウングレードになる（採用不可）。
- ⇒ **新特徴量を本番モデルへ投入しない**（安全第一・未検証オーバーレイ禁止／条項5「完了は
  数値改善が確認できた場合のみ」）。実弾稼働は現行モデルを維持する。
- ライブ V1/V2 モデルは **base `FEATURE_COLS`（不変・69 列）** を使用するため、本特徴量追加に
  よる本番推論への影響は無い（`prev_trouble_proxy` は PRERUN/LEAKFREE 経由で研究系のみ）。
  → **システムは現行の検証済みモデルで安全に稼働継続**。
- 本特徴量はコード上に保持（研究資産）。設計見直し（トリガー条件・他特徴量との交互作用・
  券種別評価）と walk-forward 全期間検証で再現性が確認できてから再検討する。

> 教訓: 単一 cutoff のOOSは誤誘導する。特徴量の採否は**複数 cutoff / walk-forward の一貫性**で
