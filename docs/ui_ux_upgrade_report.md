## 1. CUI（ターミナル）— ハッカーのコックピット化

**新設**: `src/ui/console.py`（`UmaConsole` / `get_console()`）
**配線**: `scripts/today_auto_runner.py`（起動バナー＋`setup_logging(use_rich=True)`）、
`src/marketing/premium_pack.py`（高EVシグナル検知時の自動出力）

### 設計原則（本番常駐プロセスを絶対に殺さない）

- rich 未インストール / import 失敗 → **plain テキストへ完全フォールバック**
- Windows cp932 コンソール → `errors="replace"` 再構成＋出力例外時の plain 縮退で **UnicodeEncodeError ゼロ**
- 非 TTY（リダイレクト・サービス実行）→ rich の端末検知でプログレス描画を自動抑制
- ファイルログ（`auto_runner.log` 等）の書式は **1 バイトも変わらない**（RichHandler はコンソールのみ）

## 3. 配信レポート — 漆黒×シャンパンゴールドのラグジュアリー HTML

### デザインコンセプト: 「プライベートバンクの調査レポート」

| 要素 | 選択 |
|---|---|
| 配色 | 漆黒 `#0B0A08` ベース＋シャンパンゴールド `#C9A227` の金箔グラデーション文字 |
| タイポグラフィ | 見出し=Shippori Mincho（明朝）・数字=Cormorant Garamond・本文=Zen Kaku Gothic New |
| 質感 | SVG フラクタルノイズのフィルムグレイン＋ゴールドの radial グロー＋ヘアライン罫（◆ 中飾り） |
| モーション | カードごとの staggered フェードイン（`animation-delay` 階差） |
