# 📘 UMALOGI 利用者マニュアル（USER MANUAL）

> 対象: AI 予想を**閲覧・参考にする利用者**。
> システムの起動・停止・保守は [OPERATIONS_MANUAL.md](OPERATIONS_MANUAL.md) を参照。

UMALOGI には目的の異なる 2 つのフロントエンドがある。

| UI | URL | 向き | 主な用途 |
|----|-----|------|----------|
| **Next.js ダッシュボード** | `http://localhost:3000` | 利用者向け | レース予想閲覧・当日購入ガイド・的中履歴 |
| **Streamlit ダッシュボード** | `http://localhost:8501` | 運用者向け | ROI トレンド・資金曲線・会場別分析 |

## 1. 予想の見方（Next.js）

### 1-1. レースを選ぶ

トップページのレースツリーから「開催日 → 会場 → レース番号」をたどる。
各レースには推定発走時刻とカウントダウンが表示される。

### 1-2. AI 予想スコアの読み方

各馬には複数モデルのスコアが表示される。

| 表示 | 意味 |
|------|------|
| **本命** | 的中率特化モデル（目的変数 `is_win`）。1 着確率が高い馬を上位に。 |
| **卍（まんじ）** | 回収率特化モデル（目的変数 `ev_target`）。Isotonic 較正済みの期待値ベース。 |
| **Alpha-Payout** | 払戻回帰モデル。期待払戻が高い馬を抽出。 |
| **Pure_EV_Edge** | 黒字化専用枠。単複・EV≥1.15・1-10 Kelly のみを通す厳選フィルタ。 |
| **EV** | 期待値 = モデル確率 × 推定払戻 / 100。**EV > 1.0 が買い目の基準**。🔥 は EV≥1.0。 |
| **Kelly 推奨額** | ケリー基準 `f* = (EV-1)/(odds-1)` による推奨購入金額。 |

> ⚠️ **重要**: 実際に賭ける「実弾」は **単勝・複勝のみ**にロックされている（確定実績分析に基づく安全策）。
> 三連系・ワイド等は「観賞用」表示であり、実投資の対象外。

### 1-3. 当日購入ガイドタブ

- 総資金・Kelly 係数をドロップダウンで変更すると推奨額が再計算される。
- 確定結果が出ると、合計投資額・払い戻し・回収率（ROI）の KPI サマリーが表示される。
- 的中行はハイライト、外れ行はグレーダウン表示。

### 1-4. 的中結果履歴タブ

AI の的中照合結果を一覧表示。モデル別フィルター・ROI/EV ソートに対応。
同着・返還も正しく按分表示される。

## 2. EV・ケリー基準の基礎知識

| 用語 | 意味 | 判断 |
|------|------|------|
| **EV（期待値）** | 1 円賭けたとき平均何円返るかの期待倍率。 | `EV > 1.0` なら理論上プラス。 |
| **ケリー基準** | 破産しない範囲で資金成長を最大化する賭け金比率。 | 係数を下げるほど保守的。 |
| **ROI（回収率）** | 払戻合計 ÷ 投資合計 × 100%。 | 100% 超で黒字。 |

> 会計上の ROI は「フラットコスト（¥100×点数）」基準で算出される。
> Kelly 実額（実発注額）とは分離されており、評価指標が賭け金の大小に左右されない設計。

## 4. よくある質問（FAQ）

**Q. 予想が表示されない／古い。**
A. 直前予想は当日のオッズ確定後に生成される。サーバー稼働状況は運用者へ確認（[OPERATIONS_MANUAL.md](OPERATIONS_MANUAL.md) のチェックリスト）。

**Q. EV が高いのに「観賞用」と出る。**
A. 実弾は単勝・複勝のみのロック仕様。三連系等は参考表示で実投資対象外。

**Q. 文字化けした馬名が出る。**
A. JVLink/netkeiba 由来のエンコーディング起因。検知時は自動で空文字または「（データ修復中）」表示になる。運用者がクレンジングを実行する。
