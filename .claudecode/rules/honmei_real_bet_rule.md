## 2. 現状の推奨戦略（複勝特化）

**現時点で本番運用するなら「複勝のみ」が唯一の根拠ある戦略。**

理由:
- 複勝のみ ROI 170.8%（黒字）
- ワイド・馬連・三連複は Harville 確率が市場オッズと乖離しており、Kelly 賭け金が期待値通りに機能しない
- 単勝は edge 黄金ゾーンでも 78.0% と未達。データ量不足の可能性あり

## 4. 流動性制限（JRAスリッページ対策）

| 制限 | 値 | 計算式 |
|------|----|--------|
| **1ベット最大投資** | **¥15,000** | `min(bankroll × 3%, ¥15,000)` |
| **1レース最大合計** | **¥50,000** | `min(bankroll × 10%, ¥50,000)` |
| 最小ベット | ¥100 | 常時適用（小残高時の MIN_BET フロアあり） |

> **注意:** `bankroll × 10% < ¥100` のとき実質ベット不能（事実上破産）。
> ¥10,000 スタートでは序盤の損失で早期に race_budget < ¥100 に到達しやすい。

---

## 5. Kelly 賭け金計算式

```
kelly_full      = (p × typical_odds - 1) / (typical_odds - 1)
effective_kelly = kelly_full × 0.05   # 1/20 Kelly
bet_size        = min(
    bankroll × effective_kelly,
    bankroll × 0.03,    # 相対上限 3%
    ¥15,000,            # 物理上限
    race_budget_remaining
)
# bet_size < ¥100 かつ kelly_full > 0 かつ race_budget ≥ ¥100 → MIN_BET(¥100) を使用
→ ¥100単位切り捨て
```

## 6. 発注トリガー条件（全券種共通）

1. **EV ≥ 1.0**: `p × typical_odds ≥ 1.0`（期待値が投資額を上回る）
2. **単勝**: さらに edge 黄金ゾーン条件を追加
3. **複勝**: edge ≥ 1.20× を追加
4. **コンボ系（ワイド/馬連/三連複）**: EV条件のみ
   - Harville確率は 1/n より小さいため edge≥1.2チェックは不適用

---

## 7. Harville 確率の活用

| 券種 | 確率計算 |
|------|---------|
| 馬連 | `P(i,j 共に1-2着) = P(i)×P(j)/(1-P(i)) + P(j)×P(i)/(1-P(j))` |
| ワイド | `Σ_{k≠i,j} P({i,j,k}が1-3着)` (正確公式) |
| 三連複 | `Σ_{6通り順列} P(a)×P(b)/(1-P(a))×P(c)/(1-P(a)-P(b))` |
| 馬単 | ❌ 除外 |
| 三連単 | ❌ 除外 |

## 9. 今後の改善方針

1. **複勝特化シミュレーション**: 複勝のみで走らせた場合の長期 ROI を確認
2. **コンボ系の閾値引き上げ**: ワイド/馬連/三連複 は EV ≥ 1.3 〜 1.5 に引き上げてベット頻度を削減
3. **単勝の edge ゾーン再最適化**: より多くの月次データで黄金ゾーンを再探索
4. **資金管理の再検討**: ¥10,000 スタートでは 1/20 Kelly でも early risk が高い。¥20,000+ 推奨
5. **データ蓄積**: 2026年全週分のバックテストが可能になった時点で再検証
