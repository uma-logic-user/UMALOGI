## 5. Kelly 賭け金計算式

```
# 単勝/複勝: race_results.win_odds が取れる場合はそれを優先
# それ以外は TYPICAL_ODDS にフォールバック
odds = win_odds if available else TYPICAL_ODDS[bet_type]

kelly_full      = (p × odds - 1) / (odds - 1)
effective_kelly = kelly_full × 0.05   # 1/20 Kelly
bet_size        = min(bankroll × effective_kelly, bankroll × 0.03, ¥15,000, race_budget)

# 小残高フェーズ: bet_size < ¥100 かつ kelly_full > 0 → ¥100（MIN_BET フロア）
→ ¥100 単位切り捨て
```

## 7. Harville確率の利用状況

| 券種 | 計算式 | 発注 |
|------|-------|------|
| 馬連 | `P(i,j 共に1-2着)` = Harville quinella | ❌ 無効化 |
| ワイド | `Σ_{k≠i,j} P({i,j,k}が1-3着)` | ❌ 無効化 |
| 三連複 | `Σ_{6通り順列} P(a)×P(b)/(1-P(a))×P(c)/(1-P(a)-P(b))` | ❌ 無効化 |
| 馬単 | ❌ 除外 | — |
| 三連単 | ❌ 除外 | — |

**Harville確率の問題点**: モデルのトップ予測馬（=市場人気馬）は実際払戻がHarville予測より大幅に低い。コンボ系は Harville EV 再校正後に再検討。

## 8. 今後の改善方針

1. **複勝 ROI 改善**: 現在93.3%（ほぼ均衡）→ 特徴量追加・モデル再訓練で 110%+ 目標
2. **単勝 ROI 改善**: 現在57.8%（赤字）→ edge 黄金ゾーンのチューニング継続
3. **コンボ系再活性化**: Harville確率の校正（市場オッズとの乖離補正）が完了したら "filtered" モードで再検討
4. **win_odds 充填**: `realtime_odds` の積極取得で Kelly 精度を改善（現在2026年は0%充填）
5. **資金拡充**: ¥10,000スタートでは1/20 Kelly でも初期損失で早期破産リスクが高い。実運用では ¥30,000+ 推奨
